온디바이스 Anisette 로그인 동작을 실제 기기에서 확인한 정식 릴리즈입니다.

## 변경 사항

- AnisetteKit / Unicorn TCI 기반 온디바이스 Anisette 지원 및 기본 활성화. JIT가 필요하지 않습니다.
- 원격 서버용·온디바이스용 프로비저닝 데이터를 별도로 보관합니다.
- `Reset adi.pb`와 헤더 보존 옵션을 추가했습니다. 초기화 시 로그아웃하며 서명 인증서는 유지합니다.
- Anisette 및 Apple 로그인 헤더를 편집할 수 있습니다.
- 로그 보기·공유·복사·삭제와 민감정보 제거 기능을 추가했습니다.
- Apple 계정 plist 변환 오류, 서버 설정 변경 반영, 일시적인 연결 오류 재시도를 개선했습니다.

## 설치 및 사용

1. 아래 `GetMoreRam.ipa`를 내려받아 SideStore 또는 AltStore로 설치합니다.
2. 기존 로그인 문제가 있었다면 설정의 `Reset adi.pb`를 실행합니다. 헤더를 유지하려면 `Keep header customizations`를 켜세요.
3. `On-Device Anisette`를 켠 상태로 로그인합니다. 첫 실행은 ADI 라이브러리를 다운로드하며 Apple 프로비저닝에 인터넷 연결이 필요합니다.
4. App IDs에서 앱을 선택해 `Add Increased Memory Limit`를 적용한 뒤 해당 앱을 다시 설치합니다.
